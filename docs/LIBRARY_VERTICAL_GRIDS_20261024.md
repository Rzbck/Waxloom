# Waxloom — vertical album, artist and favorite-track grids

Date: 2026-10-24. Based strictly on previously deployed Web `7dcd8360f2c04f95e021fbfbea270c6b4fa2411a`.

## Owner request / root cause
Albums were split into independent 40-cover horizontal "More records" carousels, requiring repeatedly manipulating a horizontally cropped shelf to browse the music. The artist library mounted its first 24 artists in a horizontal carousel with a "More artists" button even though the server had 1,476 artists. Center-aligned album/artist names didn't belong under a continuously shifting vinyl focus, leading to difficult-to-read labels. The artist/playlist open overlay used the literal escaped string `&nearr;` in JSX, which React displayed verbatim. Favorites separately displayed artists, albums and tracks, rather than just favorite songs.

## Changes (frontend only)
- **Albums:** a single compact vertical CSS Grid, auto-fill desktop and 2+ columns on mobile. Cover card includes up to two readable title/artist lines, single/album distinction and a small Play action. Clicking artwork opens the original album detail. Hover/focus on desktop raises the black vinyl disc and subtly enlarges cover without disturbing scroll position. Mobile retains native vertical touch scroll. Navidrome albums are fetched by existing `/api/library/albums` in **80-album pages**, with an IntersectionObserver sentinel requesting the next page near viewport; no "More records" buttons or duplicate groups. Request epochs prevent fast filter changes from showing stale results; the existing sorting tabs and Refresh remain functional. No new API or service.
- **Artists:** the same progressive vertical cover grid for all 1,476 returned artists; only 48 React cards at first, adding 48 as the user scrolls. Native `loading=lazy` for later images, `decoding=async`; full names accessible via `title` and buttons. No "More artists" button. The broken `&nearr;` overlay was removed from artists and corrected to a genuine `↗` glyph for Playlists.
- **Favorites:** **only tracks**, shown as the same responsive artwork grid; clicking a cover plays the chosen real song in the ordered favorites queue, with quick Like/Unlike and Add-to-playlist actions. Artists and Albums sections removed from Favorites, without touching their stored favorites on Navidrome.
- **Context:** Album detail, artist detail, Search artist/album groups and Playlists continue functioning. Home's already approved song-first horizontal vinyl and Discovery are unchanged; the album/artist grid classes are distinct and do not inherit the focus-rack transforms. No touches to owned music, database, Docker volumes, credentials or running production API.
